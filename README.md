#  - VLESS tunnel on GitHub Codespaces

After creating the codespace, the VLESS link will be saved in **`vless.txt`** file in the root of your repository.

## How to get the link

- Open the terminal in your codespace (or use the VS Code interface)
- Run: `cat vless.txt`
- Copy the output into your v2rayNG or any Xray client

The codespace will automatically stop after 10 minutes of inactivity (no active connections).
